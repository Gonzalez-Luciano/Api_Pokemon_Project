# Pokémon Search Tool

Pokémon Search Tool es una aplicación web desarrollada con **React** y **Bootstrap** que permite buscar Pokémon de manera rápida y sencilla. Utiliza la **PokeAPI** para obtener datos en tiempo real y mostrarlos con un diseño limpio e interactivo.

## 🚀 Demo

Podes probar la aplicación en el siguiente enlace:
👉 [Pokemon Search Tool](https://pokemon-search-tool.netlify.app)

## 📌 Características

- Búsqueda instantánea de Pokémon por nombre.  
- Información detallada de cada Pokémon.  
- Estilos dinámicos con Bootstrap para una mejor experiencia visual.  
- Consumo de datos en tiempo real desde la **PokeAPI**.  

## 🛠️ Tecnologías utilizadas

- **React** - Librería para construir la interfaz de usuario.  
- **Bootstrap** - Framework CSS para un diseño atractivo y responsivo.  
- **PokeAPI** - API pública para obtener datos de los Pokémon.  

## 📦 Instalación y ejecución

1. Clona el repositorio:
   ```bash
   git clone https://github.com/tu-usuario/pokemon-search-tool.git
   ```
2. Accede a la carpeta del proyecto:
   ```bash
   cd pokemon-search-tool
   ```
3. Instala las dependencias:
   ```bash
   npm install
   ```
4. Inicia la aplicación en modo desarrollo:
   ```bash
   npm start
   ```

La aplicación se ejecutará en `http://localhost:3000/`.
